# ARVADS
### Bangladesh Measles Intelligence & Risk-Aware Decision-Support Dashboard

An interactive public-health dashboard for exploring historical measles trends, outbreak patterns, and risk-aware decision-support insights in Bangladesh.

## About

ARVADS presents Bangladesh's measles situation through interactive data visualization and historical trend analysis.

The dashboard covers WHO JRF annual confirmed measles cases from **1980–2025**, alongside laboratory-confirmed 2026 cases (up to 23 October), enabling historical comparison and a broader understanding of measles trends.
